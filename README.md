# NGO Awareness Webpage – InAmigos Foundation

## 📌 Project Overview

This project is a simple NGO Awareness Webpage developed using HTML and CSS.

The website aims to spread awareness about the initiatives and social impact of InAmigos Foundation by showcasing its mission, ongoing projects, event activities, and volunteer opportunities.

---

## 🎯 Objectives

- Introduce InAmigos Foundation
- Highlight ongoing projects and initiatives
- Showcase social impact and achievements
- Display event and activity photographs
- Encourage volunteering and community participation
- Provide contact and social media information

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome Icons
